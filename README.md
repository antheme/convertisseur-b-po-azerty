# convertisseur-bépo-azerty
convertisseur bépo vers azerty

Code circuitPython à flasher sur un waveshare rp2350 USB A

Permet d'utiliser un clavier bépo sur un pc windows sans intallation de pilote.
La conversion de caractères se fait à la volée par le circuit.

Dépendance : adafruit-hid, à trouver dans le bundle adafruit circuitPython
